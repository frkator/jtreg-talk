# A JVisualBook presentation on jtreg: how the JDK tests itself, where jtreg complements JUnit and TestNG, and why passing tests do not mean everything intended was tested.

Presentation materials for the Dublin JUG talk on 23 September 2026.

# Run the presentation

Use JDK 25+ and the locally built JVisualBook JAR. From this directory:

```bash
java -jar ../jvisualbook/target/jvisualbook-1.4.2.jar --dir . --port 8080
```

*gif rendering and text colors depend on the private modification of jvisualbook which will be uploaded soon
